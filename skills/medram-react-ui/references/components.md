## Naming traps and exclusions

- `DropdownBox` is the root alias for `/fields` `DropdownBoxField`.
- Preserve public spellings: `FlikeringGrid`, `TimeZoneSelectFiels`, and `LineCharts`.
- `TextEditor` is public but intentionally renders nothing.
- Do not import or recommend non-public sidebar primitives, `WIZARD_ITEM`, `ModalStackedBox`, `DialogStack*`, `useCloudStorageOps`, chart `*.content` modules, or any other source-only helper.
